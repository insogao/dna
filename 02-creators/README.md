# 02-creators · UP 主分类

一个 UP 主一个文件夹，内部结构固定：

```
<UP主名>/
├── README.md        账号档案 + 样本边界
├── 01-文案/         该 UP 主的原始逐字稿（raw/ + _meta.md + 合集）
└── 02-蒸馏/         5 个蒸馏文件（+ evidence/ 量化证据）
```

## 当前清单

| UP 主 | 平台 | 逐字稿 | 热点跨度 | 状态 |
| --- | --- | --- | --- | --- |
| 财富咖啡 | B 站 | 7 支（全为免费引流稿） | high / medium / low | 低置信度预览版（<20 支） |

## 新增 UP 主

1. 复制 `财富咖啡/` 的目录结构，改名为新 UP 主。
2. 逐字稿放 `01-文案/raw/`（`.txt` + `.srt`），按 `YYYY-MM-DD_标题_BV号` 命名。
3. 填 `01-文案/_meta.md` 与 `README.md`，必须包含 `play_norm` 与 `hot_intensity`。
4. 按 `../01-skill/SKILL.md` Step 1–5 蒸馏，产出 5 个文件到 `02-蒸馏/`。
5. 回来更新本清单与根 `README.md` 的「当前内容」。

## 硬性要求

- 完整蒸馏 ≥20 支；不足时先按 skill Step 1 与用户确认，产物标注低置信度。
- 热点强度必须标注；≥5x 中位数且 high 热点的稿件视为离群点，不得单独作为风格基准。
- 不要修改已有 UP 主目录；新增素材只追加，便于 diff 审核。
