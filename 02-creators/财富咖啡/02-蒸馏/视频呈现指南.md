# L6 视频呈现指南

> 通用文章蒸馏器的 L6 分析配图数量、字号层级、加粗密度；对视频口播稿不适用，本层全部重写。

## 封面（固定模板，只换变量）

- 16:9（约 1146×717），AI 生成电影感暗黑末日底图 + 后期叠字；橙金细描边 + 四角装饰。
- 顶部 35% 压暗留白；第 1 行金黄粗黑钩子，第 2–3 行白色粗黑，危险词红色；6–8px 黑描边 + 投影。
- 中心放一个象征物（钞票炸弹 / 金色数字 7 / 天平），右下或左下放人物特写；配风暴闪电、崩塌天际线、红色下跌曲线。
- **底图 Prompt 不变，只换 4 个变量**：`[SYMBOL_OBJECT]` / `[FIGURE]` / `[LANDMARK_OR_MARKET]` / `[DISASTER_ELEMENT]`，再换叠字。封面文字是标题的二次提炼，不必与标题相同。

## 正片

- 真实纪实 B-roll（发布会 / 街景 / 港口 / 交易所 / 办公室），语义匹配即可，每 4–8 秒一切；正片不用 AI 图。
- 左上角固定角标水印「品牌名 + 平台 logo」，全片不动；换平台只换水印。
- 底部居中**烧录硬字幕**：白字 + 黑描边，单行 ≤18 字，48–56px @1080p。
- 单一男声、全片无口误与填充词、语速恒定（高度符合 TTS 或模板化口播，未做声纹鉴定）。
- 低频紧张氛围垫乐 −22~−26dB，推演段抬 2dB。
- 1920×1080 / 25–30fps / 单 P / 12–35 分钟 / 无分 P。

## 发布与复用

- 约 4 天 1 条，每月 6–7 条；时段分散在 7–8 点、17–18 点、21–23 点。
- 免费引流稿 : 充电专属 ≈ 1 : 3；免费稿选最有话题爆点的，试看段给足实质信息。
- 标签 7 个左右：财经 / 金融 / 深度 / 信息差（固定）+ 事件人物机构词。
- B 站简介极简；YouTube / 播客端写满章节时间码 + 免责声明 + 关键词堆。同一稿三平台复用，只换标题、封面、水印、简介。
