# Writing-DNA · 财经长视频口播稿（总入口，不是唯一必读）

语料：7 支全片逐字稿 / 53,500 字 / 152.1 分钟。**v2 口径**：情绪词去「最」、按逐支相关 + 热点强度定权重。
> **低置信度预览版**：当前 7 支，低于完整蒸馏门槛 20 支；按 `SKILL.md` Step 1 需先与用户确认是否接受，或补足语料后重跑差分校验。
**只复刻写法，不搬原文的事实、观点与金句。** 写作前还必须另读 `语言DNA.md`、`脚本结构模板.md`、`选题与认知框架.md`、`视频呈现指南.md`，以及 5 篇相关原文。

## 1 语言（哪些是约束，哪些只是诊断）

语速 **350 字/分**全片匀速；短句为主，单行 ≤18 字。
**可作约束**（剔除 15.2x 离群点后仍正向）：时间压迫 ≈3.3/千字、权威机构提及 ≈72.0 次/片、认知承诺 ≈2.28/千字。
**只作诊断、不设配额**：情绪极端（去噪后爆款 6.6/千字，目标 6–7，允许更低，**不要为凑密度堆「最 / 超级 / 顶级」**）、观众点名、互动指令、数字。
词库：核弹 / 底裤 / 绞肉机 / 保卫战 / 细思极恐 / 低维度 / 斩钉截铁 / 连夜 / 自毁长城 / 疯狂 / 惨烈。
禁用：重要 / 显著 / 值得注意的是 / 综上所述 / 首先其次最后。
机构名反复撒（彭博社 / 董事会 / 司法部 / 华尔街）；数字参考全片 25–35 个、单段可短冲 8–9，**没有「每 5 分钟 ≤6」的硬阈值**。

## 2 结构（25 分钟 / 约 7000 字）

```
0:00  极端比喻钩子：具体的人 + 巨额数字 + 爆炸意象
0:10  复述大众误解（吃瓜视角 / 老套剧本）
0:30  强硬推翻：「请立刻停止这种低维度的…」「那你就完全没看懂…」
0:50  只抛一个疑点，标题承诺在此原样兑现
1:15  互动指令（常见但非必备，全片建议 ≥4 次）
1:30  时间线铺垫 → 推翻表层解释
6:00  结构性原因：三笔账 / 三方博弈
12:00 历史对照：1976 / 2008 / 日本
18:00 三种结局推演，一律「若…则…」
22:00 两条待观察的线 + 升维金句 + 立场题 + 免责声明
```
「1:16 报栏目名」只在 1/7 支出现过，**不是通用件**。
每 5 分钟至少 1 次「反转推翻」语（7 支实测每桶均 ≥1）；情绪词不中段归零。结尾不给封闭答案。

## 3 选题

压成「一个具体的人 + 做了反常的事」，压不成不做。72h 热点、能落普通人钱包、能找历史对照、有 3 个封面符号。
配比：突发地缘 50% / 政策 20% / 长周期 20% / 书籍理论 10%。
**必标热点强度**（high / medium / low）；热点 high 的稿件播放量不可归因于写法。
反例：纯概念开场 + 抽象指标清单 → 情绪词 3.13/千字、互动 1 次、播放低一个量级。

## 4 素材、事实纪律与动机判断

外媒报道 → 公开声明 → 可核实时间线 → 历史对照数据。每个判断跟 1 个可核实事实或数字并标来源与时间；传闻写「据报道」，推测写「一种可能是」。不做个股建议、不承诺收益、片尾免责声明。
**动机判断一律写成假设**：凡「为什么他要这么做 / 背后真实意图」，用「一种可能是 / 若…则…」，禁止「本质上是 / 一定是」；标注**信息截至日期**与**可证伪条件**（「若 X 发生，本判断不成立」）。L5 的「没有偶然」只是叙事框架，不是事实断言——曾有前作把道歉信判成「我不会走」，4 天后当事人辞职。

## 5 认知框架

表层解释往往有更深的利益与制度动因；宏大事件要折回普通人；结论不封闭；把观众从「低维度吃瓜」抬到「看懂全局」——身份赋能比信息量更重要。以上均为**叙述视角**，不构成对现实的断言。

## 6 续集选题（同主题后续）

1. 找出同主题前作，列出其核心判断、信息截至日期、可证伪条件。
2. 开头明确回扣「上次我们说…」，再给后续关键事实。
3. **前作判断错了就认账**：直接写「这个判断错了」并说明错因，不模糊改写、不删旧结论。
4. 把错因升级成规则（动机揣测 → 收紧假设措辞；数据过期 → 收紧截止日标注）。
5. 前作是 5 篇 few-shot 原文的必选一篇；标题封面标「后续 / 更新」，不拿旧结论当新钩子。

## 7 呈现

封面 AI 底图固定模板只换 4 个变量 + 叠字；正片真实 B-roll 每 4–8 秒一切 + 左上角固定水印 + 烧录硬字幕；单 P / 1080p / 12–35 分钟；免费 : 充电 ≈ 1 : 3；一稿三平台只换标题、封面、水印、简介。

## 8 写稿流程（保留完整格式与 few-shot）

1. **读全部 5 份产物**：本文件 + `语言DNA.md` + `脚本结构模板.md` + `选题与认知框架.md` + `视频呈现指南.md`，一份都不能跳过。
2. **读 5 篇相关原文**：按 `_meta/` 的题材与表现档位从 `raw/` 筛 5 篇（超过取最近 5 篇，不足用同体裁补齐；同主题续集必须含前作），**通读全文**，读完要能说出共同语感。
3. 按第 2 节骨架生成 25 分钟稿，每段附 `[B-ROLL]` 关键词。
4. 跑自检表；不像就对照分层产物逐项重写。再做事实核查，风格与事实冲突时事实优先。

## 交稿自检

- [ ] 语料数量已确认（≥20 支或用户已接受低置信度预览）；热点强度已标注
- [ ] 写作前 5 份分层产物全部读过，5 篇原文通读且能说出共同语感
- [ ] 标题疑点在前 90 秒被原样复述并立案
- [ ] 语速 350±20 字/分；每 5 分钟 ≥1 次「反转推翻」语
- [ ] 时间压迫 / 权威提及 / 认知承诺达标；情绪词 6–7/千字且没有堆「最」
- [ ] 数字全片约 25–35 个，连续两段未破 10
- [ ] 每个动机句都是假设措辞，有信息截至日期与可证伪条件
- [ ] 若属续集：已回扣前作、错判已认账、前作已进 few-shot
- [ ] 结尾留 2 条待观察的线 + 未来日期；没有搬用原文的事实、观点、金句

## 边界

结论是相关性不是因果（n=7/6，不显著）；15.2x 离群点 + high 热点稿不得单独作为风格基准。播放量还受热点热度、发布时点、推荐池影响。转写有专名误识，引用需标注。只复刻写法，不冒充原作者。
