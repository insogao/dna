## L3 选题判定

- 必须能压成一句话：**一个具体的人 + 做了反常的事**。压不成就不做。
- 打分卡（≥4 分开工）：72h 内有新闻触发 / 有具体人物数字可上封面 / 能写出「表层解释是错的」/ 能落到普通人钱包 / 能找到历史对照 / 能凑出 3 个封面符号 / 不碰红线。
- 四类配比：突发与地缘危机 ≈50% · 政策与税制 ≈20% · 长周期命题 ≈20% · 书籍理论 ≈10%。
- **热点强度必须标注**（high / medium / low，编辑填写）：热点 high 的稿件播放量不可归因于写法，蒸馏时要单独剔除或降权。
- 反例：纯概念开场「如果一个国家欠的钱太多会发生什么」、通篇抽象条件与指标清单 → 情绪词 3.13/千字（去噪口径）、互动 1 次、播放 2.1 万，热评「专业词汇太多，似听天书」。

## L4 素材纪律

- 优先级：外媒报道 → 公司/机构公开声明 → 可核实时间线 → 历史对照数据。
- 每个判断后跟 1 个可核实事实或数字，标注来源与时间；未证实传闻写「据公开信息 / 据报道」，推测写「一种可能是 / 若…则…」。
- 不做个股买卖建议、不承诺收益；片尾固定免责声明。风格与事实冲突时事实优先。

## L5 认知框架（含可证伪边界）

1. 表层解释往往是错的，背后可能有利益、制度与权力博弈。
2. 宏大事件最终折回「普通人的钱包与身份」。
3. 结论不封闭，事件永远有下一条线在走。
4. 把观众从「吃瓜的低维度」抬到「看懂全局」——身份赋能是核心情绪价值。

> **边界（重要）**：「没有偶然、全是精密计算」是**叙事框架，不是事实断言**。BV13iWT6NEWT 把道歉信解读为「我不会走 / 主动切割风险」，4 天后黄仁勋即辞职，该动机判断被后续事实推翻。严禁把揣测动机写成定论。

### 动机判断规则（新增，硬性）

- 凡涉及「为什么他要这么做 / 背后真实意图」的结论，**一律写成假设**：「一种可能是…」「若…则…」，不得用「本质上是 / 一定是 / 根本不是」。
- 每支稿标注**信息截至日期**（片尾或简介），并给出**可证伪条件**：「若 X 发生，则本判断不成立」。
- 后续事实出现时，按「续集处理」回扣并认账，不悄悄改写旧结论。
- 自检：通读成稿，把所有动机句找出来，逐句确认是假设措辞 + 有截止日期 + 有证伪条件。

## 续集选题处理（新增）

本次题目若与已有前作同主题（例如爆款稿的后续），必须：

1. 检索语料库中同主题前作，列出前作的**核心判断、信息截至日期、可证伪条件**。
2. 新稿开头明确回扣：「上次我们说…」，接着给出此后发生的关键事实，不装作第一次讲。
3. **前作判断被证伪要认账**：直接写「这个判断错了」，说明错因（信息截止日 / 框架过度确定 / 动机揣测），不模糊改写、不删旧结论。
4. 把「错在哪」升级为规则：若是动机揣测翻车，收紧 L5 的假设措辞；若是数据过期，收紧信息截至日期标注。
5. 前作是 5 篇 few-shot 原文的**必选一篇**，用来对齐语气与叙事连续性。
6. 续集标题与封面标注「后续 / 更新」，但不得用旧结论当新钩子。
