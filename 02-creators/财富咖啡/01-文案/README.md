# 01-文案 · 财富咖啡逐字稿

## 文件

- `raw/*.txt` — 全片逐字稿纯文本（whisper.cpp turbo-q5 转写）。
- `raw/*.srt` — 带秒级时间码，用于按 5 分钟分桶统计。
- `逐字稿合集.md` — 7 支全文合订，按 5 分钟分段、段首时间锚。
- `_meta.md` — 逐支元数据：播放、`play_norm`（÷中位数）、`hot_intensity`、时长、日期。

## 口径

- 转写来自公开视频音频，非官方字幕；专名有误识（如 Mega SPD、达里欧），引用需标注。
- `hot_intensity` 为人工估计，待编辑确认；≥5x 且 high 的稿件按离群点处理。
- 语料只用于风格研究与流程审核，不搬运原文观点与内容，详见根 `NOTICE.md`。

## 新增素材

放 `raw/` 下同名 `.txt` + `.srt`，更新 `_meta.md` 与 `逐字稿合集.md`，再按 `../../../01-skill/SKILL.md` 重跑蒸馏。
