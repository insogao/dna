# Finance Video DNA

面向**视频口播长稿**的风格蒸馏与一致性写稿。语料是带时间码的转写逐字稿，产物是可执行的量化规则，不是形容词式的风格描述。

## 一、与通用文章蒸馏器的关系

**完整保留（不魔改）**：目录格式、`_meta/` 元数据、五份分层产物 + `Writing-DNA.md` 的整合结构、每次写作前重读全部产物 + 5 篇相关原文的 few-shot 校准、写作优先级、规则冲突处理、写后逐项自检。这几条解决的是「风格一致性」，与文章还是视频无关，予以保留。

**只改视频场景必须改的五处**：

| 维度 | 通用文章版 | 本 skill |
| --- | --- | --- |
| 语料 | ≥20 篇完整文章 | **≥20 支**全片逐字稿，带 srt 时间码；不足按 Step 1 先确认 |
| L6 视觉 | 配图数量 / 字号层级 / 加粗密度 | 封面 AI 模板 / B-roll / 硬字幕 / 水印 / 时长 / 发布配比 |
| 风格描述 | 词频表 + 句式清单 + 定性总结 | **每千字密度 + 每 5 分钟分布 + 语速**，可机器校验 |
| 差分 | 只看单个作者的共性 | **逐支相关 + 归一化播放 + 热点强度**，剔除离群点，蒸馏"什么带来传播" |
| 事实纪律 | 复刻写法不搬内容 | 额外加：来源标注、推测措辞、动机假设可证伪、免责声明 |

**为什么保留 5 份 + 5 篇**：分层产物是压缩后的共性（可检查的规则），原文是不可压缩的语感（句子呼吸、短句位置、段落接法）；两者不能互相替代。长稿写到中段模型会回归默认书面语，每轮重读把风格从「权重里的模糊记忆」重新锚定成「当前窗口里的具体证据」。本类账号虽高度模板化，仍保留这条，只把 5 篇原文的选取改成按 `_meta/` 的题材与表现档位匹配，避免随机取样。

## 一·二、统计口径（v2，硬性）

1. **词表去噪**：泛用副词/最高级（如「最」）不得计入情绪词。实测「最」单独贡献 224 次命中、占原统计 47.8%，把密度虚高到 11.16/千字；剔除后爆款为 6.6/千字。禁止为凑密度堆「最 / 超级 / 顶级」。
2. **单支爆款不得当基准**：播放量用 `单支播放 ÷ 频道中位数` 归一化；≥5x 且热点强度 high 的稿件标记为离群点，其写法贡献与事件热度无法分离，必须降权或单独列出。本项目离群点为 15.2x。
3. **逐支相关而非分组取值**：对 `log10(播放)` 与各指标算 Pearson r，同时给出「剔除最大离群点」后的 r。只有两个口径都保持正向的指标才能写成硬约束；其余只作诊断，不设配额。
4. **样本量声明**：n<20 时所有 r 值只作方向参考、不具统计显著性，文档必须标注 n 与口径。
5. **热点强度必填**：`hot_intensity`（high / medium / low）由编辑填写，缺省不得输出归因结论。

## 二、目录格式（沿用通用版，按 UP 主分目录）

```
corpus/<UP主名>/
├── raw/                    # 原始逐字稿 .txt + .srt
├── _meta/                  # 每支一个 JSON
├── 语言DNA.md              # L1
├── 脚本结构模板.md          # L2
├── 选题与认知框架.md        # L3–L5
├── 视频呈现指南.md          # L6（替换原「视觉风格指南」）
└── Writing-DNA.md          # 整合文档，≤4000 字
```

`_meta/` 必填字段：`标题 / 日期 / 时长 / 播放 / play_norm / hot_intensity / 信息截至日期 / 免费或充电 / 题材标签 / 表现档位`。
多个 UP 主时各占一个子目录，互不干扰；根目录 `全部逐字稿.md` 是给其他 AI 审核的自包含汇总。

## 三、工作流

### Step 0 · 语料采集

用 `fast-zh-transcript` skill：yt-dlp 取音频 → ffmpeg 16k mono wav → whisper.cpp turbo-q5 → txt + srt。
优先取**免费引流稿**（充电专属稿匿名取不到音频流）。每支同时存 `.txt` 与 `.srt`。
新增 UP 主：建 `corpus/<UP主名>/raw/` 放稿，运行 `build_corpus.py` 重建合集。

### Step 1 · 语料数量确认（硬性，不可跳过）

1. 统计 `raw/` 下**完整**逐字稿数量 N，并计算频道播放中位数与每支 `play_norm`。
2. **完整蒸馏门槛：N ≥ 20**，且覆盖不同时期、不同题材、不同热点强度、不同表现档位。
3. 检查 `hot_intensity` 是否每支都已标注；缺失的先请编辑补齐。
4. 若 N < 20：**暂停正式蒸馏，先向用户确认**，报告三件事：
   - 实际数量 N 与缺口（20 − N）；
   - 影响：词频不稳、结构分类覆盖不足、相关性可能被单支离群点主导（本项目 3 支→7 支就有两个结论被推翻，15.2x 离群点剔除后情绪词 r 从 0.399 掉到 0.043）；
   - 两个选项：**A** 接受「低置信度预览版」，产物必须标注实际数量、样本边界与热点强度；**B** 补足语料后再蒸馏。
5. 未获明确确认不得输出正式蒸馏结论；用户已确认的，把确认结果写进 `_meta/`。
6. 当前状态：`财富咖啡` 7 支，属低置信度预览版，待用户确认。

### Step 2 · 元数据

按上文必填字段逐支记录。`play_norm` 用于识别离群点，`hot_intensity` 用于归因降权，`信息截至日期` 供动机判断与续集回扣使用。

### Step 3 · 量化分析与差分

1. 对 srt 按 5 分钟分桶，统计语速、每千字的各类词密度、数字、权威机构提及、开头/结尾原文。
2. **按「一·二」口径去噪后**，逐支算 `log10(播放)` 与各指标的 Pearson r，并复算「剔除最大离群点」后的 r，输出 `相关性报告.json`。
3. 只有两个口径都正向的指标写入 `语言DNA.md` 的「可作约束」；其余写入「只作诊断」。
4. 分组均值表仅作展示，**不得据其单列取值**（爆款组可能只有 1 支）。

### Step 4 · 分层蒸馏

| 层 | 输出 | 关键问题 |
| --- | --- | --- |
| L1 语言 | `语言DNA.md` | 去噪词表、可作约束 vs 只作诊断、禁用词 |
| L2 结构 | `脚本结构模板.md` | 开场动作逐条标注**通用 / 单支特征**；每 5 分钟推翻密度；规则必须能被自家数据验证 |
| L3 选题 | `选题与认知框架.md` | 可复述钩子判定、四类配比、反例、热点强度标注 |
| L4 素材 | `选题与认知框架.md` | 来源标注、推测措辞、数字诊断口径（不设硬阈值） |
| L5 认知 | `选题与认知框架.md` | 核心命题、身份赋能机制、**动机假设可证伪边界** |
| L6 呈现 | `视频呈现指南.md` | 封面模板变量、B-roll、字幕、水印、时长、发布配比 |

> L5 边界：「没有偶然、全是精密计算」是**叙事框架，不是事实断言**。本项目前作把道歉信判为「我不会走」，4 天后当事人辞职，动机判断被后续事实推翻。所有动机结论必须可证伪。

### Step 5 · 整合

`Writing-DNA.md` ≤4000 字，只保留**可执行规则 + 阈值 + 自检表**；定性描述留在分层产物里。
整合文档是总入口，**不是唯一必读**——具体语感只存在于分层产物和原文。
所有规则必须与 `量化报告.json` / `相关性报告.json` 对得上；自检表里不得出现表里无数据的字段名或与数据冲突的硬阈值。

### Step 6 · 使用蒸馏产物写作（完整版，保留 few-shot）

**6.1 每次写作前必读全部产物**（一份都不能跳过）

| 读什么 | 提取什么 |
| --- | --- |
| `语言DNA.md` | 高频词、句长分布、可作约束的指标、禁用词 |
| `脚本结构模板.md` | 匹配本次体裁的结构骨架与时间码；区分通用件与单支特征 |
| `选题与认知框架.md` | 切入角度、素材偏好、核心命题、动机判断边界 |
| `视频呈现指南.md` | 封面变量、B-roll、字幕、水印、发布配比 |
| `Writing-DNA.md` | 总体约束与优先级 |

**6.2 读 5 篇相关 `raw/` 原文**

1. 按 `_meta/` 的 `article_type` / `topic_tags` / `band` 筛选与本次题材最接近的；
2. 匹配超过 5 篇时取时间最近的 5 篇；不足 5 篇用同体裁不同题材补齐；
3. `_meta/` 缺失时按文件名日期与标题判断；
4. **同主题续集必须包含前作**（见 6.5）；
5. **通读全文**，不是只读开头。目的是校准分层产物写不出来的东西：句子的呼吸感、段落怎么接、什么时候突然一个短句；
6. 读完要能说出这 5 篇的**共同语感**，再开始写。读原文不是为了找素材。

**6.3 写作优先级**

用户本次明确指令 > 匹配当前体裁的结构模板 > 语言特征与视频呈现 > 认知框架。
原文里的具体观点和事实**不能直接搬进新稿**——复刻写法，不搬内容。

**6.4 动机判断（硬性）**

- 凡涉及「为什么他要这么做 / 背后真实意图」的结论，**一律写成假设**：「一种可能是…」「若…则…」，禁止「本质上是 / 一定是 / 根本不是」。
- 每支稿标注**信息截至日期**，并给出**可证伪条件**：「若 X 发生，则本判断不成立」。
- 自检时把所有动机句逐句过一遍，确认措辞、截止日期、证伪条件三样齐全。

**6.5 续集选题处理**

题目与已有前作同主题时（本次即为爆款稿的后续）：

1. 检索语料库中同主题前作，列出其**核心判断、信息截至日期、可证伪条件**。
2. 新稿开头明确回扣：「上次我们说…」，接着给出此后发生的关键事实，不装作第一次讲。
3. **前作判断被证伪要认账**：直接写「这个判断错了」，说明错因（信息截止日 / 框架过度确定 / 动机揣测），不模糊改写、不删旧结论。
4. 把错因升级为规则：动机揣测翻车 → 收紧 6.4 假设措辞；数据过期 → 收紧截止日标注。
5. 前作是 6.2 五篇 few-shot 的**必选一篇**。
6. 标题与封面标注「后续 / 更新」，但不得拿旧结论当新钩子。

**6.6 写后自检与重写**

按下方自检表逐项检查；输出不像时，对照 `语言DNA.md`、`脚本结构模板.md`、`选题与认知框架.md` 逐项自检后重写，不要只凭「读起来像不像」微调。

### Step 7 · 质检

量化对比成稿与语料基线（只校验「可作约束」的指标，其余仅诊断）；再做事实核查：每个数字标来源、推测用「若…则…」、动机句有截止日与证伪条件、片尾免责声明。风格与事实冲突时，**事实优先**。

## 四、自检表

- [ ] Step 1 语料数量已确认（≥20 支或用户已接受低置信度预览）；`hot_intensity` 每支已标注
- [ ] 离群点已识别并降权；所有规则来自两个口径都正向的指标
- [ ] 写作前 5 份分层产物全部读过，5 篇原文通读且能说出共同语感
- [ ] 标题疑点在前 90 秒被原样复述并立案
- [ ] 语速 350±20 字/分；每 5 分钟 ≥1 次「反转推翻」语（字段名与统计表一致）
- [ ] 时间压迫 / 权威提及 / 认知承诺达标；情绪词 6–7/千字且没有堆「最」
- [ ] 数字仅作诊断（全片约 25–35 个、单段可短冲 8–9），无「每 5 分钟 ≤6」式硬阈值
- [ ] 单支特征（如「1:16 报栏目名」）未被升格为通用规则
- [ ] 每个动机句都是假设措辞，有信息截至日期与可证伪条件
- [ ] 若属续集：已回扣前作、错判已认账、前作已进 few-shot
- [ ] 结尾留 2 条待观察的线 + 未来日期；没有搬用原文的事实、观点、金句

## 五、边界

- 只复刻写法，不冒充原作者，不搬运原文内容与观点。
- 语料取自公开视频；付费/私密内容需先确认处理权限。
- 公开发布时建议标注为风格参考写作。
- 蒸馏结论是**相关性**不是因果；播放量还受热点热度、发布时点、推荐池影响。单支高播放 + high 热点稿不得单独作为风格基准。
- 转写存在专名误识，引用原文时标注，不作为事实依据。
- 低置信度预览版的结论，补足语料后必须重跑相关性与差分校验。
